# 시나리오 분석: NLU/NLG 루프 현상 및 진도 제어 개선 시나리오

이 문서는 `logs/agent_trace.log`의 분석을 바탕으로, 사용자가 자연어 처리(NLP) 1강 개요 요약 요청 후 학습을 진행하는 과정에서 NLU/NLG 관련 소크라테스식 질문 루프에 갇히는 문제 상황(Failure Case)과, 프롬프트 개선을 통해 해결된 이상적인 흐름(Success Case)을 시나리오로 정리한 문서입니다.

---

## 1. 문제 상황 시나리오 (Failure Scenario)

### 대화 흐름
* **Turn 1**:
  * **Student**: "1강 자연어처리 개요 요약해줘"
  * **Tutor**: "자연어처리는 컴퓨터가 인간의 언어를 이해하고 생성할 수 있도록 하는 기술로, 인간의 언어를 분석하고 의미를 파악하는 자연어 이해(NLU)와 자연스러운 언어를 생성하는 자연어 생성(NLG)으로 구성됩니다. 이 기술은 텍스트 분류, 감성 분석, 기계 번역 등 다양한 언어 관련 문제를 해결하는 데 기여합니다."
  * **Tutor's Question**: "이 개념을 통해 우리가 일상에서 사용하는 언어와 컴퓨터 간의 소통이 어떻게 이루어질 수 있을지에 대해 생각해본다면, 어떤 점이 가장 흥미롭고 도전적이라고 느끼시나요?"
* **Turn 2**:
  * **Student**: "다시 1강 자연어처리 개요 요약 해줘"
  * **Tutor**: "자연어처리는 컴퓨터가 인간의 언어를 이해하고 생성할 수 있도록 하는 인공지능의 한 분야로, 자연어 이해(NLU)와 자연어 생성(NLG)으로 나뉩니다. NLU는 텍스트나 음성을 분석하여 의미를 파악하는 과정이고, NLG는 인간이 이해할 수 있는 자연스러운 언어를 생성하는 과정입니다."
  * **Tutor's Question**: "이 두 가지 과정이 자연어처리의 목표인 컴퓨터와 인간 간의 자연스러운 소통에 어떻게 기여하는지에 대해 생각해본다면, NLU와 NLG 각각의 역할은 무엇이라고 할 수 있을까요?"
* **Turn 3**:
  * **Student**: "NLU와 NLG의 역할과 정이 그리고 차이를 잘 모르겠어" (오타 포함)
  * **Tutor**: "NLU(자연어 이해)는 컴퓨터가 인간의 언어를 분석하고 그 의미를 파악하는 과정으로, 문장의 구조, 단어의 의미, 문맥 등을 이해하는 데 중점을 둡니다. 반면, NLG(자연어 생성)는 컴퓨터가 인간이 이해할 수 있는 자연스러운 언어를 생성하는 과정으로, 질문에 대한 답변 생성, 텍스트 요약 등을 포함합니다."
  * **Tutor's Question**: "이 두 과정의 차이를 더 깊이 이해하기 위해, NLU가 잘못된 해석을 할 경우 NLG에 어떤 영향을 미칠 수 있을지 생각해볼 수 있을까요?"
* **Turn 4**:
  * **Student**: "NLU와 NLG는 역할이 명확히 다르고 독립적인것 같아서 영향이 없을것 같아"
  * **Tutor**: "NLU와 NLG는 각각의 역할이 다르지만, 실제로는 서로 밀접하게 연결되어 있습니다. NLU가 잘못된 해석을 할 경우, NLG가 생성하는 언어의 정확성과 자연스러움에 영향을 미칠 수 있습니다. 예를 들어, NLU가 문장의 의미를 잘못 이해하면, NLG는 그 잘못된 정보를 바탕으로 부정확한 답변이나 문장을 생성할 수 있습니다."
  * **Tutor's Question**: "이러한 상호작용을 고려할 때, NLU와 NLG가 독립적으로 작동할 수 있는지에 대한 논의는 어떻게 진행될 수 있을까요?"
* **Turn 5 (핵심 문제 발생)**:
  * **Student**: "다음 내용 진행해줘" (또는 "1강에서 NLU와 NLG 다음 내용으로 넘어가줘")
  * **Tutor (루프 반복)**: "NLU와 NLG의 상호작용을 이해하는 것은 자연어처리 시스템의 설계와 성능 향상에 매우 중요합니다. 예를 들어, NLU가 제공하는 정보의 정확성이 NLG의 결과물에 직접적인 영향을 미친다면, 두 시스템 간의 협력적 접근이 필요할 것입니다."
  * **Tutor's Question**: "이와 관련하여, NLU와 NLG가 함께 작동할 때 발생할 수 있는 문제점이나 도전 과제는 무엇일까요? 그리고 이러한 문제를 해결하기 위해 어떤 방법들이 있을 수 있을까요?"

### 문제점 원인 분석
1. **Query Contextualizer (쿼리 재구성기)의 한계**:
   * 학생이 "다음 내용 진행해줘" 또는 "1강에서 NLU와 NLG 다음 내용으로 넘어가줘"라고 요청했을 때, Query Contextualizer는 이전 대화 주제인 "NLU와 NLG의 상호작용"에 갇혀 standalone query를 `'NLU와 NLG의 상호작용과 함께 작동할 때 발생할 수 있는 문제점 및 도전 과제와 이를 해결하기 위한 방법에 대해 설명해줘.'` 와 같이 재생성함.
   * 이로 인해 Vector RAG 검색이 여전히 NLU/NLG 관련 문서 조각들만 가져오게 됨.
2. **Supervisor (소크라테스 튜터)의 진도 제어 부족**:
   * RAG 결과물로 NLU/NLG 내용만 계속 들어오기 때문에, Supervisor 역시 새로운 주제(전통적 NLP의 핵심 구성 요소인 형태소 분석, 구문 분석 등이나 한국어의 언어적 특징)로 넘어가지 못하고 NLU/NLG 상호작용 질문을 지속적으로 던짐.

## 2. 해결 및 개선 시나리오 (Success Scenario)

프롬프트가 개선되어 사용자의 진도 변경 의도를 올바르게 이해했을 때의 시나리오입니다.

### 대화 흐름
* **Turn 1 ~ Turn 4**: (이전과 동일하게 NLU/NLG에 대해 소크라테스식 대화 진행)
* **Turn 5 (진도 변경 요청)**:
  * **Student**: "다음 내용 진행해줘" (혹은 "1강에서 NLU와 NLG 다음 내용으로 넘어가줘")
  * **Query Contextualizer의 개선된 Query**: `"자연어 처리 개요 1강에서 NLU, NLG 이후에 소개되는 개념 및 전통적 자연어 처리 핵심 구성 요소 (형태소 분석, 구문 분석, 의미 분석, 담화 분석) 또는 한국어의 언어적 특징"`
  * **RAG 검색 결과**:
    * `"자연어처리 개요 • 자연어처리의 핵심 구성요소(전통적 자연어처리 구성요소) 형태소 분석 구문 분석 의미 분석 담화 분석"`
    * `"한국어의 언어적 특징 ●문장에서의 생략이 많음 ●자유로운 어순 ●동음이의어가 많음"`
  * **Tutor**: "좋습니다! NLU와 NLG의 기본적인 역할과 상호 관계를 잘 정리해 보았네요. 이제 자연어 처리 개요 1강의 다음 진도로 나아가 볼까요? 강의자료에서는 전통적인 자연어 처리의 구성요소로 형태소 분석, 구문 분석, 의미 분석, 담화 분석을 단계별로 다루고 있습니다."
  * **Tutor's Socratic Question**: "이 단계들 중 가장 첫 번째 관문인 '형태소 분석'에서, 한국어의 어떤 언어적 특징이 분석을 어렵게 만드는 주요 원인이 될까요?"

## 3. 테스트 시나리오 케이스 (Test Scenario Cases)

### 테스트 케이스 1: 다시 요약해달라는 요청 시 진도 Progression
* **상황**: 학생이 NLU/NLG 요약을 1회 받은 후 "다시 1강 자연어처리 개요 요약 해줘"라고 말함.
* **기대 동작**: 이미 설명한 NLU/NLG의 기본 정의를 반복 설명하는 것이 아니라, 1강 내의 다음 주제(전통적 NLP 구성요소 또는 한국어 특징)로 검색 쿼리를 재생성하고 이에 대한 요약과 소크라테스식 질문을 제공함.

### 테스트 케이스 2: 명시적 진도 변경 요청
* **상황**: 학생이 NLU/NLG에 관한 소크라테스식 질문 도중 "다음 내용 진행해줘" 혹은 "다음으로 넘어가자"라고 응답함.
* **기대 동작**: 이전 주제(NLU/NLG)에 대한 질문 루프를 탈출하고, 1강 강의 자료 내 다음 순서 내용으로 쿼리를 작성하여 RAG가 새로운 정보를 로드하게 함.
